# UI review (v52)

Playtest notes: the conditioning manager was on Session, Urge, and Profiles, and every collapse carried up, down, pin, and hide. The Bio-Logger hid urgency and saturation behind the gear.

## Session

Before: a full conditioning manager (New, Retake, Edit pacing, Duplicate, Rename, Delete, Export, Import, Export all, pacing, change-check) sat above Full Session. The Bio-Logger sliders were inside a panel the gear opened and closed.

After: that manager is gone. Full Session setup has one **Conditioning ▸** choice. Picking it opens a short list of saved conditioning profiles and a **Manage → Profiles** link. While a conditioning session is selected, the same short list sits by the hidden profile menu. Urgency and saturation sliders stay on the Bio-Logger. The gear opens the babysitter tools only.

## Urge

Before: the same manager was the first block on the tab, above drinks and Natural Urge.

After: the manager is gone. The existing control menu has one **Conditioning ▸** entry. Choosing it shows a second menu of saved conditioning profiles, defaulting to the active one, plus **Manage → Profiles**.

## Profiles

Before: the manager, then the quiz hub, gear, and campaign, as one long page. Quizzes and calibration also lived under Settings.

After: three sections, each a collapse you can drag: **Conditioning profiles** (the only full manager), **Quizzes** (the conditioning quiz, Quiz A/B hub, and the practice editors), **Calibration** (bladder lab, symptoms, partials, sleep). Protection, campaign, and the other profile blocks stay on this tab.

## Settings

Before: Calibration & Conditioning opened the quiz, the bladder lab, symptoms, partials, and sleep. The page told you to use up and down on every section.

After: Calibration & Conditioning is a short link to Profiles. The lab itself is not copied here. Section headers use a **≡** grip. Press and hold, then drag. Pin and hide are in the **⋮** menu on the header. Reset layout still clears the saved order. The bottom tab list still has up and down, because the tab bar stays icon-only.

## Log, Path, Calendar

No conditioning manager was added. The collapse grip and menu apply to any collapse on those tabs the same way.
